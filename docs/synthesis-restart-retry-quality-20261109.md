# 装備合成を再起動後も再送する

WebとMobileでは、クラウド合成を送信する前に素材IDと再送キーを本人の端末へ一件保存します。持ち物画面で「再送」を押すと、素材が表示されていなくても同じ内容を送ります。起動時は保存を読み込むだけです。Webのクラウド合成はWeb Locks対応ブラウザーを使用します。

復元した操作の応答を受けた場合は、持ち物を通常のクラウド同期で更新します。過去の応答から結果装備を作り直さないため、すでに売却された装備が戻ることはありません。未送信だった場合は、再送によってサーバーが合成を一度だけ確定します。別の合成を始めるには、先に保留の結果を受け取るか、確認して保留を解除します。解除するのは端末の再送記録で、サーバーに届いた合成は取り消されません。

ログアウトでは本人の保留を隠し、退会後は本人の保存を削除します。Webは同じブラウザー内の複数タブが同時に送信したり、送信中に別タブが解除したりしないようにします。匿名の合成は従来どおり端末で処理します。

Webの画面とMobileのProviderを作り直す回帰、Chromiumの複数タブ、ローカル実DB／Edgeで未送信と確定・売却済みの両方を検証します。端末プロセスの実終了と再起動、Web／Mobileのテーマ別の表示比較、実stagingは別途確認します。
