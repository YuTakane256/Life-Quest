# ADR-003: タスク報酬は生涯1回、全副作用を含む

- 状態: 承認済み（人間決定 2026-07-04）
- 関連Issue: #502・#506・#512

## 文脈

Web現行の `useTaskStore.toggleComplete`（src/stores/useTaskStore.ts:245-290）は報酬台帳を持たず、タスクの完了→取消→再完了を繰り返すたびにXPが再付与される（トグル周回でXPを無限に稼げる）。一方Mobileの `rewardLedger`（packages/core/src/gameState.ts）はタスクIDに対して生涯1回しか付与しない。両者は意味的に矛盾しており、サーバー権威化にあたりどちらかへ統一する必要があった。

## 人間決定

**タスク・サブタスクの完了報酬は1つの対象につき生涯1回とする（Mobile方式へ統一）。** この「1回」はXPだけでなく、次の**全ての副作用**をひとまとめに含み、初回完了時にのみまとめて発生させ、2回目以降の完了操作では一切発生させない。

- 付与XP
- タスク消化数（`gacha_count` の加算）
- ガチャ進行に伴うマイルストーン判定
- 宝箱の生成
- 繰り返しタスクの次回分生成
- 習慣の全達成ボーナスも同型（同じ日付に対して1回のみ、上記全副作用を含む）

## 実装原則

上記の副作用は、`reward_transactions` への挿入（`insert ... on conflict (user_id, kind, source_id) do nothing`）が**実際に新規行を作成できた場合にのみ**（`get diagnostics row_count` で判定）まとめて実行する。**XPだけを条件分岐の外に置いてはならない**（この誤りは設計レビューで一度混入し修正された。#502参照）。

未完了へ戻す操作（Undo/取消）は表示状態のみを変更し、既に付与済みの報酬は取り消さない（台帳は単調増加）。

## 帰結

- Webの現行トグル周回可能な挙動は、クラウド同期導入時点で**仕様変更**となる（ユーザー向けの告知が必要になる場合がある）
- WebのUndo（5秒猶予）はクライアント演出として維持できる（RPC呼び出しを5秒遅延させる。#512）
