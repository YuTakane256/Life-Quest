# 決着した戦闘結果を再起動後に再送する

クラウド戦闘が勝利・敗北で終わると、Webはブラウザーの保存領域、Mobileは端末の保存領域に、本人の戦闘ID・行動列・再送キーを1件保存します。保存完了後に送信します。応答を受け取る前にアプリを閉じても、同じアカウントでマップを開けば「保存した戦闘結果を再送する」から同じ内容を送れます。保存に失敗した場合は、開いている戦闘結果画面から保存と送信を再試行できます。

復元時は、本人の確定済み結果を同期できれば保留表示を解除します。再送した場合も、報酬やステージ進行はサーバーが確定した内容を通常の同期で受け取ります。保留中は新しい戦闘を始める操作を止めます。再起動後のマップでは、再送できない保存を確認操作付きで破棄することもできます。破棄した未送信結果は報酬を受け取れなくなります。Webは同じブラウザーの複数タブで競合しないように、クラウド戦闘の開始から決着までと、再起動後の再送・破棄にWeb Locksを使います。ログアウト後の保留は別アカウントに表示されません。退会後は進行中の書き込みを待ってから端末データを消します。Webには退会済みの利用者IDをハッシュ化した印だけを残し、古いタブから結果を書き戻せないようにします。

WebとMobileの画面テストでは、結果送信時の通信失敗後に、アプリをマウントし直してゲームデータを復元します。ローカル実DBとEdgeのテストでは、未送信とサーバー確定後の応答喪失から同じキーで再送し、報酬が1件になることを検証します。

対象は決着後に保存が完了した戦闘です。残りは、端末プロセスを終了した場合の実操作、WebとMobileのライト／ダーク表示比較、戦闘途中の続行、宝箱と合成の保留操作です。
