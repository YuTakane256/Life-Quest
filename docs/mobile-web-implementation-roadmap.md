## 共通の完了条件

### ポートフォリオ向けの直近優先度（2026-10-13）

READMEに全画面を掲載するための全面統一を先に目指すのではなく、アプリの目的と見た目が伝わる部分を優先します。上の表は全体の作業範囲を残すもので、全Issueを今すぐ順番に実装するという意味ではありません。

1. 日々の達成を記録するタスク・習慣の主要一覧：実装・比較済み。
2. 成長と次の目標を示すキャラクターのプロフィール・XP・宝箱ロードマップ・装備：主要部分を優先して実装・比較。#694の全条件完了とはしない。
3. 成長の先にある攻略を示すマップ・バトル：戦闘前のマップ/ステージ選択と、戦闘中の画像/HP/スキル/ログ・勝敗の代表画面をWeb準拠化・比較。自動/手動の進行差・履歴/リプレイまで含む#697の全面完了とはしない。

この3領域で「達成 → 成長 → 攻略」をREADMEに示せる主要部分が揃います。直近は掲載目的の画像追加を増やすより、変更した導線の回帰・保存/同期・小画面/文字サイズなどの品質確認を優先します。未掲載画面の全面統一は必要性を見て後続へ回します。

### 各変更の検証条件

- 同じ架空匿名データ、日時、テーマ、状態のWeb/Mobile画像をPRに掲載。402×874を先行、390×844回帰維持。

- 操作テスト、型検査、既存CI3ジョブが成功。画像だけで同期/報酬/永続化を合格にしない。
- 原則1まとまりずつIssue/PR。未マージPRへの依存を明記。自動マージしない。

## 境界

UI統一でDB・同期API・保存形式・報酬計算を変更せず、保存データを初期化しない。比較データは専用parity開発アプリ・クラウド未設定に限定し、メモリ上で使用する。通常版/preview/サインイン済み環境には投入しない。

新ゲーム機能や大規模基盤変更は後回し。重大な不具合・セキュリティは優先し、UI変更と別PRで修正。
