# Web匿名のタスク報酬台帳

対象: [#720](https://github.com/YuTakane256/Life-Quest/issues/720)。匿名の同一タスク・サブタスクの再完了で、XP・タスク消化数・宝箱が重複しないようにします。2026-10-14。

## 動作

- `task:ID` / `subtask:ID` をゲーム保存領域の `completionRewardKeys` に記録します。未完了への取消や削除では台帳を消しません。
- タスクの5秒取消猶予内なら付与しません。付与済みタスクの再完了は操作として可能ですが、追加報酬はありません。
- 繰り返しタスクの次のインスタンスは別IDなので通常どおり報酬を得ます。古いインスタンスの再完了から、さらに次のインスタンスを重複生成しません。
- 匿名報酬はWeb Locks内で最新の保存データを読み、台帳・XP・消化数・節目の宝箱を1つのlocalStorage書き込みで確定してから画面へ反映します。
- 同じオリジンの匿名タブ間では、報酬だけでなく通常のゲーム保存・クラウドシード・リセットも同じロックで直列化します。古いタブのプロフィール等の書き込みでも、新しい台帳・報酬残高・宝箱を消さないようにし、匿名の保存イベントでゲーム状態を再取得します。ロックを待つ保存は非同期になり、前の認証世代の書き込みは破棄します。
- 保存不可・台帳破損・Web Locks非対応の場合は付与を止め、画面にエラーを表示します。保存環境を直した後、未完了に戻して再完了してください。Web Locksを利用できるブラウザー・実行環境が必要です。
- 遅れて届くタスク報酬や別タブの更新は、進行中の戦闘のプレイヤースナップショット・行動履歴を破棄しません。ページ再読み込み時の安全化と、起動中の更新を区別します。

これは全データの汎用的な複数タブ同期ではありません。装備操作・戦闘・習慣などの競合解決を、この修正だけで保証するものではありません。

## データ移行・クラウドとの境界

- 保存キーとZustandのversionは維持し、ゲーム保存データへ台帳と保存元区分を追加します。既存XPを再計算・減算せず、データを初期化しません。
- 台帳がない旧データでは、残っている完了済みタスク/サブタスクと、対応バージョンのcanonical台帳を証拠として引き継ぎます。取消済み・削除済みでもcanonicalの証拠があれば保持します。どちらにも証拠がない過去の付与は復元できません。
- 新しいWebデータでは完了表示だけを付与済みと推定しません。5秒の取消待機中のタスクを、canonical変換で誤って付与済みにしないためです。
- ローカルの台帳は件数で切り捨てません。保存容量が不足したら付与を止めます。canonical/クラウドの既存件数上限は変更しません。
- バックアップにはゲームデータの一部として台帳も含まれます。設定画面の保存・復元は、待機中のゲーム保存を完了させてから同じロックで読み取り・書き換えます。バックアップの明示的な復元は保存状態を置き換える既存仕様であり、古いバックアップを含めた不正防止を保証するものではありません。
- 初回クラウド移行は既存の `rewardLedger` 入力に台帳を渡します。クラウドからのシードはそのアカウントの台帳に置換し、ログアウト時のストアクリアでは台帳もクリアします。認証復元中のローカルシードでは匿名台帳を保持します。
- サインイン後の権威は従来どおりサーバーです。DB、同期API、XP量、バトルの再挑戦報酬は変更しません。
- 起動時のセッションが無効なのにクラウド用キャッシュが残っている場合、ゲーム・タスク・習慣・称号の元の保存文字列を `life-quest:cloud-session-recovery:v1:*` へ退避してから匿名用の初期状態へ切り替えます。通常の匿名データはクリアせず、別アカウントへ前の台帳を移しません。退避に失敗したら元のキャッシュを保持し、保存環境の確認/再ログインを案内します。退避データは自動復元せず、古い退避コピーも上書きしません。
- 統計は付与成功時だけ記録しますが、ゲーム報酬とは別保存です。統計保存だけ失敗した場合も、確定済みの報酬を再付与しません。

## 検証

```bash
npm run typecheck
npm test
npm run test:core
VITE_SUPABASE_URL= VITE_SUPABASE_ANON_KEY= npx playwright test --workers=1
```

単体/ストア統合テストで、取消、再読み込み、サブタスク、削除後、繰り返し、同時付与、古いタブの保存、容量不足、旧データ移行、バックアップ、保留報酬の再照合、認証世代の切替を確認します。

Web E2Eは架空の匿名データをUIから作成し、達成→スターター開封→勝利→取消/再完了→再読み込みと、実際の2タブからの同一タスク完了、ロック待機中の別タブのプロフィール保存を確認します。Web Locks非対応のエラーをPC/スマホ幅・両テーマで確認します。通常のブラウザープロファイルは使いません。

エラー画面: [PC・ライト](screenshots/anonymous-rewards/desktop-chromium-light-error.png) / [PC・ダーク](screenshots/anonymous-rewards/desktop-chromium-dark-error.png) / [スマホ幅・ライト](screenshots/anonymous-rewards/mobile-chromium-light-error.png) / [スマホ幅・ダーク](screenshots/anonymous-rewards/mobile-chromium-dark-error.png)。Webのみの変更であり、Mobileに同じエラーUIを追加していません。

Mobileの取消トーストと追加ボタンの重なりは[#721](https://github.com/YuTakane256/Life-Quest/issues/721)で別対応です。クラウド同期・Android/Apple認証の実機確認など、#699/#700の未検証範囲は引き続き残ります。
